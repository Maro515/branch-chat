ここでのやり取りは本線や分岐には残りません。要点だけが会話マップに入り、AI が把握します

設定

多くの LLM が同じ形式（OpenAI互換）の API を備えているので、接続先とモデル名を入れれば使えます。料金はその API の従量課金です。この接続では Web検索・連携ツール（MCP）・思考量の指定は使えません。キーはこの端末の中にだけ保存され、バックアップのファイルには入りません。
判定のとき、各ブランチの要点（題名・話題・結論）だけが送信されます。会話の本文は送りません。キーはこの端末の中にだけ保存されます。未入力の間は簡易判定で表示します。
すべての会話は、この端末の中にファイルとして自動で保存されます（会話ごとに JSON と、そのまま読める Markdown）。

上のどちらのファイルも読み込めます
  • ファイルに入るもの: すべての会話（全ブランチ・要約・分岐予定・モデル設定）と、知識マップの関連度。
  • 入らないもの: 設定と各種のキー。移した先で入れ直してください。添付画像は表示用の縮小版だけです。
  • 読み込みは足し合わせです。今ある会話は消えません。同じ会話が両方にあるときは、最後の発言が新しい方を残します。
